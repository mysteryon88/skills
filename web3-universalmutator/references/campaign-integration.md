# Campaign integration

The standalone `web3-universalmutator/` tree is the canonical runtime source. The `smart-contract-mutation` collection contains a byte-identical materialized runtime mirror; its maintainer `sync_universal.py --check` and packager reject drift. Packaging differences are only omission of standalone `VERSION`, its maturity guide, source tests/fixtures/caches and the packager. Runtime SKILL, agents, references and helper scripts do not import another set. The standalone version file is packaging metadata, not required by a collection skill.

The collection coordinator owns current-state snapshots, Git worktree lanes, private environments, baseline/canary/native calibration, detached supervision, resumable events and independent final verification. These features are not provided by the legacy focused `run_campaign.py` helper. Use its live mode only inside an already disposable checkout; `--allow-dirty` is an explicit isolation attestation for such a checkout, never permission to overwrite an original project.

For Foundry projects prefer and calibrate installed `forge test --mutate` before selecting an external generator. Add Universal Mutator when its rule layers bring a useful independent operator or language route. Validate installed rule files/CLI, not assumptions about all PyPI versions. As of the collection's short live check, installed Universal Mutator 1.14.1 contains TON common/FunC layers and generates actual FunC mutants; this does not prove every installation has those layers.

The collection uses `mutate <source> <language> --noCheck --mutantDir <private-dir>` as **generation only**, after confirming flags and language evidence. It then applies each file in its worktree, compiles and tests it through the owned supervisor. This deliberately replaces native `analyze_mutants` exit-code classification so failed compilation/runner errors do not become behavioral kills. Preserve the generated inventory and all results; invalid, timed out, skipped and equivalent remain separate. In the legacy collector, absent category files are unknown, not inferred zero; K/(K+S) excludes other recognized outcomes.

Primary command/rule implementation: [Universal Mutator](https://github.com/agroce/universalmutator). The native analyzer can count a nonzero command exit as a kill; inspect logs before interpreting that as test sensitivity.
