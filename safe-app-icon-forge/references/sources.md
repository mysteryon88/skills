# Sources and provenance

The merged implementation was developed from two supplied skill archives. No network source was required for normal runtime behavior or the bundled artwork.

Project-specific external references belong in `provenance.json`, not this release document. For each reference record source, author/rightsholder, license, access date, permission, optional local SHA-256, whether it is inspiration-only, and whether any asset was copied. A copied asset without license and permission metadata blocks the project.
